=== 1. CADASTRAR VENDEDOR ===
Método: POST
URL: http://localhost:8081/api/auth/register
Body (raw -> JSON):
{
  "nomeCompleto": "Vendedor Teste",
  "cpfCnpj": "111.111.111-11",
  "senha": "senha123",
  "tipo": "VENDEDOR"
}


=== 2. CADASTRAR COMPRADOR ===
Método: POST
URL: http://localhost:8081/api/auth/register
Body (raw -> JSON):
{
  "nomeCompleto": "Comprador Teste",
  "cpfCnpj": "222.222.222-22",
  "senha": "senha123",
  "tipo": "COMPRADOR"
}


=== 3. LOGIN VENDEDOR ===
Método: POST
URL: http://localhost:8081/api/auth/login
Body (raw -> JSON):
{
  "cpfCnpj": "111.111.111-11",
  "senha": "senha123"
}
* Copie o token retornado para usar na autorização do Passo 4 e 5.


=== 4. CRIAR EVENTO E INGRESSO ===
Método: POST
URL: http://localhost:8081/admin/eventos
Authorization: Bearer Token -> (Cole o token do Vendedor)
Body (raw -> JSON):
{
  "titulo": "Festival de Software",
  "descricao": "Evento focado em tecnologia",
  "tipoEvento": "TECNOLOGIA",
  "dataEvento": "2026-11-20T10:00:00",
  "quantidadeIngressos": 50,
  "valorIngresso": 120.00
}


=== 5. LISTAR EVENTOS ===
Método: GET
URL: http://localhost:8081/admin/eventos
Authorization: Bearer Token -> (Cole o token do Vendedor)
Body: (Vazio)


=== 6. DELETAR EVENTO ===
Método: DELETE
URL: http://localhost:8081/admin/eventos/1
Authorization: Bearer Token -> (Cole o token do Vendedor)
Body: (Vazio)


=== 7. LOGIN COMPRADOR ===
Método: POST
URL: http://localhost:8081/api/auth/login
Body (raw -> JSON):
{
  "cpfCnpj": "222.222.222-22",
  "senha": "senha123"
}
* Copie o token retornado para usar na autorização do Passo 8 e 9.


=== 8. COMPRAR INGRESSO ===
Método: POST
URL: http://localhost:8081/comprador/ingressos/comprar
Authorization: Bearer Token -> (Cole o token do Comprador)
Body (raw -> JSON):
{
  "ingressoId": 1,
  "quantidade": 2
}


=== 9. LISTAR MEUS INGRESSOS (COMPRADOR) ===
Método: GET
URL: http://localhost:8081/comprador/ingressos
Authorization: Bearer Token -> (Cole o token do Comprador)
Body: (Vazio)
